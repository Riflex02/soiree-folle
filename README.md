# 🎉 Soirée Folle

100 jeux de soirée entre potes (Action ou Vérité, Undercover, Loup-garou, quiz, jeux de bar…) et un mode **🌐 Jouer en ligne** : chacun joue sur son téléphone avec un code de salon.

👉 **Jouer : https://riflex02.github.io/soiree-folle/**

Sur iPhone : ouvre le lien dans Safari ➜ bouton Partager ➜ « Sur l'écran d'accueil ».
Sur Android : ouvre le lien dans Chrome ➜ menu ⋮ ➜ « Installer l'application » (ou installe l'APK).

L'abus d'alcool est dangereux pour la santé, à consommer avec modération.
